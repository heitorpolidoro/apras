APRAS-66 — Slug do condomínio

Campo editável na tela Sistema → Perfil do condomínio (/admin/tenant-profile, APRAS-61). Lido de GET /api/v1/tenant-profile, gravado pelo mesmo PATCH /api/v1/tenant-profile sob a permissão já existente tenants:profile_update. Nenhuma rota nova, nenhuma permissão nova.

Decisão do operador (2026-09-21): o slug é editável e não haverá tabela de histórico. Links antigos simplesmente param de funcionar — custo aceito.

Alterar o endereço do condomínio?

O endereço mudará de /c/condominio-solar-da-serra para /c/solar-da-serra.

Todos os links salvos, impressos ou compartilhados com o endereço antigo deixarão de funcionar. Não há redirecionamento.
