APRAS-70 — Condomínios

Menu Administração → Condomínios (/admin/tenants), regra { superuser: true } em ROUTE_ACCESS — mesmo padrão de /admin/modules. Lê GET /api/v1/tenants e cria por POST /api/v1/tenants. Nenhuma rota nova, nenhuma migração.

Anotações. GET /api/v1/tenants não aceita skip/limit e devolve tudo ordenado por nome: por isso não há paginação, e sim filtro de texto e de situação no cliente (D4). A coluna Situação é somente leitura — desativar é PATCH /tenants/{id} e não pertence a esta tela (D5). Trocar o slug é feito no Perfil do condomínio (/admin/tenant-profile), depois de alternar para aquele condomínio (D3).

Novo condomínio

Obrigatório, 1 a 120 caracteres, único em toda a instalação.

O endereço do condomínio é derivado do nome pelo sistema e pode receber um sufixo numérico se já estiver em uso. Ele é exibido depois de salvar, e pode ser alterado no Perfil do condomínio.
Anotações. O formulário pede só o nome (D1): TenantCreate não tem campo slug. Não há prévia do slug no cliente (D2) — app/core/slug.py é a única autoridade da derivação. O corpo enviado é { "name": "…" }; is_active é omitido e o backend cria ativo.

Residencial Altos da Serra VI

Endereço: residencial-altos-da-serra-vi-2

Anotações. O slug exibido é o do corpo do 201 (TenantRead.slug), nunca um palpite do cliente. Ao concluir, a chave TanStack ["tenants"] é invalidada — a mesma que o TenantContext usa, então o seletor de condomínio passa a mostrar o novo sem recarregar. O botão de convite é o ponto de encaixe da APRAS-72 (D7).

Novo condomínio

Já existe um condomínio com esse nome.

Anotações. tenant.name é único globalmente: TenantAlreadyExistsError → 409 (D6). A mensagem é traduzida no cliente, e não o detail em inglês do backend. O formulário continua aberto, o texto digitado é preservado e a lista não é recarregada. Um 422 ou qualquer outra falha cai em parseApiError com a chave genérica da página.

Acesso restrito

Você não tem permissão para acessar esta área.

Anotações. RestrictedAccessMessage renderizado no lugar, sem redirecionamento, exatamente como em /admin/modules. A regra { superuser: true } lê o usuário real, então "ver como" nunca abre a tela. O item do menu usa o mesmo objeto de regra. Um tenant_admin cai aqui: POST /tenants é superusuário e responde 403 para ele.
