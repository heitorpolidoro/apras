Perfil do condomínio

Arquivo recusado

Formatos aceitos: PNG, JPEG e WebP. Tamanho máximo: 2 MB.

  • brasao.svg — image/svg+xml recusado no cliente
  • fachada.png — 3,4 MB recusado no cliente
  • logo.png — bytes corrompidos 422 do backend

Em todos os casos tenant.logo_url permanece inalterado e nenhum arquivo é gravado.

Acesso restrito

Você não tem permissão para acessar esta área.

RestrictedAccessMessage renderizado no lugar da página (sem redirecionamento). O item de menu também não aparece: a regra é { anyOf: ["tenants:profile_update"] }, e as três rotas de escrita respondem 403.

Consequência, sem uma linha alterada no relatório

project_report_service já lê tenant.logo_url. O cabeçalho passa a exibir o logo enviado:
