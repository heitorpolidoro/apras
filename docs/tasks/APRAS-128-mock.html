/admin/modules and /subscription - package cards

One card per package: checkbox, the package title in bold and, for a bundle, the list of features it switches on together. A single module is a card with its title only. Presentation group headings stay above the cards.

Existing split tenants (question 1)

A (spec default): migration switches the missing member ON (tasks on, categories off becomes both on).

B: migration switches the remaining member OFF (both off; the tenant loses tasks).
